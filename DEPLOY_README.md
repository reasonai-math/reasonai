# ReasonAI — public expert demonstration package

This is a **privacy-reduced public demonstration** derived from the 21 October 2026 final prototype. The original 25 pupil responses and research JSON files are deliberately **not included**. It is not the full research-case review version.

## Publish using GitHub Pages
1. Open your GitHub repository, choose Add file > Upload files.
2. Upload the **contents** of this folder (index.html and the five JavaScript/CSS assets) to the repository root. Do not upload the source ZIP or any research JSON.
3. Commit changes. In Settings > Pages choose Deploy from a branch, main, /(root), Save.
4. Wait for GitHub to show the live URL and test it in a private/incognito window and on a second device.

## Important limits
- GitHub Pages for a repository may publish source files publicly. Never include identifiable or restricted research records.
- Each browser stores demo records in its own localStorage; data is not automatically synchronized, backed up, or submitted to the research team.
- The existing expert validation form must be distributed and collected separately.
- This version uses a different browser storage key to avoid automatically loading previous locally stored research cases when opened on the same browser.
- Test all five game stages, HOTS enrichment, independent reassessment, and progress report before sending the link to experts.
- The code is a prototype and has not undergone a full accessibility/security review.
